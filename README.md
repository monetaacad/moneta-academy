# 모네타 아카데미 — 서버

모든 학생이 같은 시간을 사는 마법 아카데미 방치형 웹게임입니다. Node.js 하나로 게임 서버, 데이터베이스(SQLite), 웹페이지를 함께 띄웁니다. **외부 패키지가 없어서 `npm install`이 필요 없습니다.**

- 레벨디자인과 성장 일정: [DESIGN.md](DESIGN.md)
- 예상 규모: 동시 접속 2,000명 기준으로 시험했습니다 (아래 「부하 테스트」).

## 1. 바로 실행

필요한 것: **Node.js 22.13 이상** (24 LTS 권장)

```bash
node server/server.js
# → http://localhost:8080 접속
```

`data/arcanum.db` 파일 하나에 모든 학생 정보가 저장됩니다.

## 2. 환경 변수

| 이름 | 기본값 | 설명 |
|---|---|---|
| `PORT` | 8080 | 서버 포트 |
| `HOST` | 0.0.0.0 | 받을 주소. nginx 뒤에 둘 때는 `127.0.0.1` 권장 |
| `DATA_DIR` | ./data | DB와 백업 폴더 |
| `SERVER_EPOCH` | 첫 실행 시각 | **개교일**. 아카데미력 1일째의 기준. 예: `2026-11-02T00:00:00+09:00`. 첫 실행 때 DB에 기록되며 이후에는 바뀌지 않습니다 |
| `ADMIN_TOKEN` | (없음) | 관리자 API 비밀값. 비워 두면 관리자 API가 꺼집니다. **24자 이상**이어야 켜집니다 (`openssl rand -base64 33`) |
| `DATA_KEY` | (자동 생성) | **개인정보 암호화 키**(32자 이상). 프로필·두상·채팅·신고 사유를 AES-256-GCM으로 암호화하고 비밀번호 후추도 여기서 만듭니다. 없으면 `data/.data.key`를 만들어 쓰니, 운영에서는 이 값을 `/etc/arcanum.env`로 옮기세요. **잃어버리면 모든 비밀번호와 개인정보를 되살릴 수 없고, 다른 키로는 서버가 켜지지 않습니다** |
| `MARKET_GRADE` | 2 | 거래소를 쓸 수 있는 최소 학년 |
| `ADMIN_IPS` | (없음) | 쉼표로 구분한 IP. 지정하면 관리자 API를 그 IP에서만 받습니다 |
| `BACKUP_KEY` | (없음) | 지정하면 백업 파일을 AES-256-GCM으로 암호화합니다 (16자 이상). 키를 잃으면 백업을 풀 수 없습니다 |
| `PUBLIC_ORIGIN` | (없음) | 서비스 주소 (예: `https://game.example.com`). 지정하면 다른 출처에서 온 쓰기 요청을 정확히 거절합니다 |
| `TRUST_PROXY` | 0 | nginx 등 프록시 뒤라면 `1` (실제 IP로 속도 제한) |
| `COOKIE_SECURE` | 0 | HTTPS로 서비스하면 `1` |
| `REGISTER_OPEN` | 1 | `0`이면 입학 신청을 막습니다 |
| `INVITE_REQUIRED` | 1 | 가입할 때 초대코드가 필요합니다. `0`이면 코드 없이 가입 |
| `MAX_PLAYERS` | 5000 | 최대 학생 수 |
| `EXPECTED_PLAYERS` | 500 | 첫 주 월드 보스 체력 계산에 쓰는 예상 인원 |
| `TIME_SCALE` | 1 | **테스트 전용.** 시간 배속. 운영에서는 절대 바꾸지 마세요 |
| `TEST_MODE` | 0 | **테스트 전용.** IP별 입학·로그인 제한을 끕니다 |

## 3. 실제 서비스 배포 (리눅스 VPS 예시)

> 처음 올린다면 **`deploy/FIRST-DEPLOY.md`**를 순서대로 따라 하세요 (서버 준비 → 설치 → 비밀값 → 서비스 → HTTPS → 첫 운영 설정 → 업데이트).

권장 사양: **1~2 vCPU, 메모리 1GB, 디스크 10GB**. 2,000명 동시 접속에서 CPU 한 코어의 10~35%, 메모리 약 190MB를 썼습니다.

```bash
# 1) Node.js 설치 (예: Ubuntu)
curl -fsSL https://deb.nodesource.com/setup_24.x | sudo -E bash -
sudo apt-get install -y nodejs nginx

# 2) 코드 올리기
sudo mkdir -p /opt/arcanum && sudo cp -r . /opt/arcanum
sudo useradd -r -s /usr/sbin/nologin arcanum
sudo chown -R arcanum:arcanum /opt/arcanum

# 3) 서비스 등록 (비밀값은 /etc/arcanum.env 에 — 방법은 deploy/arcanum.service 맨 위 주석. SERVER_EPOCH, PUBLIC_ORIGIN도 고치세요)
sudo cp deploy/arcanum.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now arcanum
sudo journalctl -u arcanum -f      # 로그 보기

# 4) nginx + HTTPS (도메인을 deploy/nginx.conf에 넣고)
sudo cp deploy/nginx.conf /etc/nginx/sites-available/arcanum
sudo ln -s /etc/nginx/sites-available/arcanum /etc/nginx/sites-enabled/
sudo apt-get install -y certbot python3-certbot-nginx
sudo certbot --nginx -d 게임.도메인.com
sudo systemctl reload nginx
```

Docker를 쓴다면 `deploy/Dockerfile`이 있습니다.

```bash
docker build -t arcanum -f deploy/Dockerfile .
docker run -d --name arcanum -p 8080:8080 -v arcanum-data:/app/data \
  -e ADMIN_TOKEN=바꾸세요 -e SERVER_EPOCH=2026-11-02T00:00:00+09:00 arcanum
```

## 4. 가입 · 초대코드

- **가입**: 이름, 비밀번호, 비밀번호 확인, **초대코드**, 기숙사를 입력합니다. 초대코드가 맞지 않거나 이미 다 쓴 코드면 가입할 수 없습니다.
- **초대코드 발급**: `https://주소/admin.html`(아카데미 운영실)에서 관리자 토큰으로 들어가 개수, 코드당 사용 횟수, 유효 기간, 메모를 정해 발급합니다. 형식은 `ARC-XXXX-XXXX`이고, 헷갈리는 글자(0/O, 1/I)는 쓰지 않습니다. 대소문자와 하이픈은 아무렇게나 입력해도 됩니다.
  - 1인 1코드: 사용 횟수 1
  - 커뮤니티 공지용 공용 코드: 사용 횟수를 크게(예: 200), 기간을 짧게
  - 누가 어떤 코드로 들어왔는지 목록에서 볼 수 있고, 코드는 언제든 중지할 수 있습니다.
- **게스트 입학은 없습니다.** 예전 `/api/guest` · `/api/upgrade`는 404입니다. (예전에 만든 게스트 계정은 비밀번호가 없어 다시 로그인할 수 없습니다.)
- **이름 금칙어**: 운영진 사칭(운영자·관리자·admin·GM 등)과 욕설·성적인 말이 들어간 학생·파티·동아리 이름은 거절합니다(`R.NAME_BAN`, 대소문자·밑줄·숫자 끼워 넣기도 걸러 냄). `ADMIN_NAMES`에 적은 이름만 가입 때 예외입니다.

## 5. 실시간 채팅

- 채팅 창은 **어느 화면에서나** 붙어 있습니다. 넓은 화면(1280px 이상)은 오른쪽 칸, 중간 화면은 오른쪽 아래 떠 있는 창, 휴대폰은 하단 메뉴 위 막대(누르면 펼침)입니다. 접어 두면 마지막 메시지 한 줄과 안 읽은 수만 보입니다.
- **RP**(역할극)와 **월드**(자유 대화) 두 채널. 한 메시지 안에서 `대사 *행동*`처럼 **별표 사이**를 행동 묘사로 섞어 쓸 수 있습니다 (「✦ 행동」 버튼이 고른 글자를 감싸 줍니다). `/me`로 시작하면 메시지 전체가 행동이 됩니다.
- 이름을 누르면 그 학생의 **정보창**(두상, 한 줄 소개, 자기소개, 레벨·전투력, 친구 신청, 가리기·신고)이 열립니다.
- 이름, 기숙사, 학년은 서버가 붙이므로 사칭할 수 없습니다. 메시지는 글자로만 보여 주어 HTML이나 스크립트가 실행되지 않습니다.
- 제한: 0.5초 안에 다시 보내기 금지(429), 1.5초에 1개(연속 4개까지), 같은 말 10초 안 반복 금지, 월드 300자, RP 500자.
- 두 번 올라가지 않게: 클라이언트가 메시지마다 번호(nonce)를 붙이고, 응답이 늦어 다시 눌러도 같은 번호로 보냅니다. 서버는 2분 안에 같은 번호가 오면 새로 올리지 않고 처음 것의 id를 돌려줍니다. 보내는 중에는 버튼이 잠깁니다.
- 학생이 할 수 있는 일: 이름을 눌러 **가리기**(내 화면에서만), **신고**.
- 운영실에서 할 수 있는 일: 신고 확인, 메시지 삭제(모든 화면에서 즉시 사라짐), 채팅 금지(10분~7일), 공지를 월드 채팅에 띄우기.
- 채널마다 최근 5,000개를 DB에 남기고, 접속하면 최근 80개를 보여 줍니다. 위로 올리면 이전 대화를 더 불러옵니다.
- **지연 로딩(월드 · RP)**: 접속(`init`)에는 `lazy:true`, 연결 번호 `cid`, 채널별 글 번호 `seq:{world,rp}`만 보내고 두 채널의 글 목록은 뺍니다. 탭을 열면 `POST /api/chat/watch {cid, ch}`로 그 연결에만 글 전체를 받고(연결이 끊기면 풀림), `GET /api/chat/history?ch=&after=ID`로 빠진 글을 오래된 순 100개까지 받습니다(더 밀려 있으면 최근 100개 + `gap:true`, 그 앞은 `before=`). 안 보는 탭은 2초마다(바뀌었을 때만) 오는 `seq` 이벤트로 안 읽은 수를 셉니다. 공지 · 파티 · 동아리 · 1:1은 그대로 실시간입니다. 방송은 80ms마다 묶어 보냅니다.
- 월드 보스가 토벌되면 월드 채팅에 자동으로 알립니다.
- **nginx를 쓴다면** `deploy/nginx.conf`에 있는 채팅 스트림 설정(`proxy_buffering off`)을 꼭 넣어 주세요. 없으면 메시지가 늦게 도착합니다.

## 5-1. 내 정보 · 두상 · 친구

- 아카데미 광장 오른쪽 위의 **내 정보** 카드, 또는 상단의 사람 모양 버튼에서 엽니다. 탭: 프로필 / 친구 / 설정.
- 프로필: 두상, 한 줄 소개(40자), 자기소개(300자), 좋아하는 과목, 레벨·전투력 공개 여부, 친구 신청 받기 여부.
- **두상**: 브라우저가 고른 그림의 가운데를 정사각형으로 잘라 계단식으로 줄여 **100×100 JPEG**(보통 3~8KB)로 만든 뒤 올립니다. 서버는 JPEG 머리를 읽어 100×100 이하인지 확인하고, 아니면 거절합니다. 두상 주소는 로그인한 학생만 볼 수 있고, 내려보낼 때 `sandbox` CSP를 붙여 그림 파일에 숨긴 코드가 실행되지 않게 합니다. 한 시간에 10번까지 바꿀 수 있습니다.
- 친구: 이름으로 신청하거나 채팅에서 이름을 눌러 신청 → 상대가 수락하면 친구. 친구 목록에 접속 여부(●)와 마지막 접속 시각이 보입니다. 최대 100명, 대기 중인 신청 30개.

## 5-0. 화면 구성 (이번 개편)

- **안내도 6칸**: 아카데미 광장 / 수업·연구(강의실·서고) / 원정·전투(원정·시험·월드 보스) / 장비·공방 / 교류·상점(파티·거래소·매점) / 기록(세계관·업적). 칸 안에서는 위쪽 탭으로 옮겨 다닙니다.
- **머리글**: 「가이드」 버튼, 그리고 내 두상 버튼을 누르면 내 정보·친구·파티·설정 메뉴가 열립니다(친구 신청·파티 초대가 오면 빨간 숫자).
- **채팅 탭**: 공지(쓰기 불가, 운영진 공지·월드 보스 소식) / RP / 월드 / 파티(파티에 있을 때) / 1:1(친구끼리). 열지 않은 탭도 실시간으로 받아 두고, 안 읽은 수를 빨간 숫자로, 다시 열면 「여기부터 새 글」 줄을 보여 줍니다. 읽은 위치는 브라우저에 학생별로 기억합니다. 1:1 내용도 DB에 암호화해 저장합니다.
- **칭호**: 조건을 채우면 열리고 내 정보에서 골라 이름 앞에 붙입니다. 설정에서 채팅의 내 칭호·다른 학생 칭호를 각각 숨길 수 있습니다(정보창에는 그대로).
- **내 정보 편집**: 저장하지 않은 내용은 탭을 옮기거나 「다른 학생에게 보이는 모습」(미리보기)을 다녀와도 그대로 남습니다. 긴 자기소개는 정보창에서 네 줄까지 보이고 「더보기」로 펼칩니다.
- **쪽지시험 삭제**: 세계관 문제는 없앴습니다. 기말시험은 이론 30(시험 과목 평균 레벨) + 실기 40 + 대련 30으로, 버튼 하나로 채점합니다. 쪽지시험이 주던 지식은 반딧불 정령 병 보상으로 옮겼습니다(성실 학생 기준 최고 학년 약 98일, 매시간 들르는 학생 약 90일).
- **오늘의 의뢰 바꾸기**: 하루 1번 무료, 그 뒤 별조각 5·10·20·40.
- **달별 축복**: 아카데미 광장의 축복 칸을 펼치면 여덟 달의 보너스와 시작까지 남은 날이 보입니다.
- **원정 일지**: 원정 화면은 그림 대신 게임 시간 25초마다 한 줄씩 적히는 일지로 보여 줍니다. 전리품은 떠날 때 미리 정해(`j.loot`, 최대 12점) 주운 시각에 실제 이름이 적히고, 받는 것은 돌아올 때입니다(중간에 취소하면 그때까지 주운 것의 절반).
- **전투 일지**: 보스 · 결투제 · 월드 보스 · 실기 대련은 캔버스 그림 대신 전투 기록(ev)을 14줄 남짓의 글로 묶어 7초쯤에 걸쳐 보여 줍니다(건너뛰기 가능).
- **NPC 학생**: 결투제 대진표의 학생 15명. 서버판에서는 **거래소에서만** 활동합니다(파티원 NPC는 아티팩트 미리보기에만). 거래소에는 15분마다 확률적으로 장비·재료를 올립니다(서버 학생들의 진도에 맞춘 레벨, 늘 8~24개 유지). NPC 물건을 사면 아르크는 사라집니다(아르크 회수 장치).

## 5-2. 파티 · 거래소

- **파티**: 최대 4명. 파티원 한 명당 원정 아르크·경험치 +3%(최대 +9%, 원정을 맡길 때 정해짐). 파티원끼리만 보이는 「파티」 채팅 채널이 생깁니다. 파티 화면에서 만들기·초대(이름 또는 정보창의 「파티 초대」)·수락·나가기, 파티장은 내보내기·파티장 넘기기.
- **거래소**: 2학년부터(`MARKET_GRADE`). 장비(장착·잠금 제외)와 재료·마석·연금술 물약을 아르크로 사고팝니다. 올리면 물건을 거래소에 맡기고, 팔리면 수수료 5%를 뺀 아르크가 판매자에게 바로 들어갑니다(접속해 있지 않아도). 3일 지나면 자동으로 돌아오고, 그 전에 내릴 수 있습니다. 한 번에 10개까지. 검색: 장비 부위·등급·이름, 재료 종류, 정렬(가격 낮은 순·높은 순·새로 올라온 순·레벨 순). 수수료는 아르크가 너무 불어나지 않게 하는 장치입니다.

## 5-3. 동아리 · 칭호 도감 · 설정 · 알림

- **동아리**: 정식 학생이면 누구나 만들 수 있습니다(이름 2~12자 중복 불가, 최대 30명). 가입 방식은 「누구나」 또는 「신청 후 승인」. 회장·부회장은 승인/거절·내보내기·공지/소개/색 꾸미기, 회장은 부회장 지정·회장 넘기기·해산. 회장은 넘긴 뒤에 나갈 수 있습니다. 가입 신청이 오면 회장·부회장에게 실시간 알림.
- **동아리 채팅**: 채팅창에 「동아리」 탭이 생기고 그 안에 **RP**(캐릭터로, `*행동*` 묘사 가능)와 **오너**(캐릭터 밖 잡담·일정) 두 갈래. 동아리원에게만 보내지며 DB 채널은 `g:<id>:rp`, `g:<id>:oc`.
- **칭호 도감**: 기록 → 칭호 도감. 모든 칭호와 얻는 방법·진행도, 바로 「달기」, 맨 위에 지금 단 칭호와 「칭호 떼기」. 내 정보에서 바로가기.
- **설정**(머리글 맨 오른쪽 톱니): 글씨 크기 5단계, 효과음 켜기·크기·종류별 끄기, 배경음악 켜기·크기·「창을 내리거나 다른 탭을 볼 때도 틀기」, 작업 완료 알림(창을 내려 두었거나 다른 탭을 볼 때, 종류별로 끄기), 채팅 칭호 숨기기 등. 화면·소리·알림 설정은 브라우저에 저장(`arc_pref`, `arc_bgm*`), 게임 설정은 서버에 저장.
- **파티**는 혼자서도 만들 수 있습니다(보너스는 다른 사람 파티원부터).

## 5-4. 우편함 · 별의 탑 · 테마

- **우편함**(머리글의 편지 버튼): 운영진이 보상을 보내는 곳. 학생은 우편을 열어 봐도 보상을 기한 안에 언제든 받을 수 있고, 새 우편이 오면 버튼에 숫자만 뜹니다(접속 중이면 실시간). 「모두 받기」도 있습니다. 같은 우편은 두 번 눌러도 한 번만 받습니다.
- **보내는 법**: 아카데미 운영실(`/admin.html`) → 우편 보내기. 받는 사람은 「모든 학생」 또는 이름 목록. 보상은 별조각·아르크·마석·마나·지식·환수의 알·토벌 도전권·희귀 장비 상자. 만료는 기본 30일, 7일/90일/1년/날짜 지정/**거의 영구(2999.12.31)**. 「나중에 가입한 학생도 받기」를 켜 두면 오픈 보상처럼 이후 가입자에게도 보입니다. 보낸 우편은 「회수」할 수 있습니다(이미 받은 보상은 그대로).
- API: `POST /api/admin/mail {title, body, rewards:{shard,…}, to:'*'|'이름1, 이름2', days | expires(유닉스 초) | forever:true, newcomers}` · `GET /api/admin/mail` · `POST /api/admin/mail/delete {id}`.
- 저장: 모두에게 보내는 우편은 한 줄만 저장하고 학생마다 읽음·받음만 따로 적습니다(`mail`, `mail_state`). 제목·내용은 암호화. 만료 7일이 지난 우편은 자동 정리.
- **별의 탑**(파티 → 별의 탑): 파티가 한 주 동안 함께 층을 쌓습니다. 도전은 학생마다 하루 3번, 도전한 학생의 전투에 파티원 모두의 힘이 실리고(접속하지 않아도), NPC 파티원은 도전자 힘의 30%씩. 1층은 그 주 첫 도전 때 파티원 진도(최고 단계 중간값 − 12)로 정해지고 한 층마다 2단계씩 높아집니다. 층을 처음 넘으면 그때 파티원 모두에게 우편(7일)으로 보상, 5층마다 장비 상자·10층마다 환수의 알. 매주 월요일 0층부터. 시뮬레이션 기준 혼자 3~5층, 4명이면 6~8층.
- **테마**: 설정 → 화면 → 테마 (밤하늘 / 한낮의 서고 / 기기 설정 따라). 색은 `style.css`의 `:root[data-theme="…"]` 토큰으로만 정하므로 새 테마는 토큰 묶음 하나와 `app.js`의 `THEMES`에 한 줄을 더하면 됩니다.
- **오늘의 의뢰**와 출석에 받을 보상이 적혀 있습니다. **거래소**: 학년이 모자라도 구경은 할 수 있고, NPC 학생은 재료도 늘 몇 묶음 올려 둡니다. 데모에서도 NPC 물건을 사고, 올린 물건이 NPC에게 팔립니다.
- **내 정보**: 누르면 다른 학생에게 보이는 모습이 먼저 나오고, 「편집」 탭에서 바꿉니다.

## 5-5. 함께 하는 콘텐츠 (하늘 · 별샘 의식 · 떠돌이 상인 · 함께 듣는 수업)

- **하늘 이벤트**: 하루 세 번(한국 시간 10~13시, 15~18시, 20~23시 중) 유성 소나기·별샘 오로라·꼬리별·구름 위의 별고래 중 하나가 30~60분 나타납니다. 날짜로 정해져서 모든 학생(데모 포함)이 같은 하늘을 봅니다. 그동안 맡긴 작업에는 겹친 시간만큼 효과가 들어가고, 「올려다보기」를 누르면 별조각·마나 조금. 화면에 하늘 효과가 그려집니다(전투 효과 줄이기를 켜면 끔).
- **별샘 의식**: 하루 한 번 마나 30분 분을 봉헌(별조각 +1). 그날 목표(최근 24시간 활동 학생의 35%, 최소 5명)를 채우면 봉헌한 모두에게 4시간 동안 경험치·지식 +15%, 아르크 +10%. 다 찬 뒤에 봉헌해도 축복을 받습니다. 진행 숫자는 실시간.
- **떠돌이 상인**: 매일 12시·20시부터 2시간, 영웅(가끔 전설) 장비 세 점 경매. 부른 아르크는 바로 맡겨 두고 더 높은 값이 나오면 즉시 돌려줍니다. 끝나기 2분 안에 부르면 2분 연장. NPC 학생도 한도까지 값을 불러 판을 채웁니다. 낙찰품은 우편(14일). 게스트는 구경만.
- **함께 듣는 수업**: 강의실에 지금 같은 과목을 듣는 학생 수가 보입니다(접속하지 않아도 수업 중이면 셈). 같은 과목을 듣는 다른 학생 1명당 과목 경험치 +1%(최대 +5%, 맡길 때 정해짐). 하루에 같은 과목을 들은 학생이 많으면(최근 활동 학생의 15%, 최소 3명) 그 교수가 공지에 한 줄을 남기고, 그날 수업 보고서에도 나옵니다.
- **별의 탑과 파티 변경**: 탑 기록은 파티의 것입니다. 새로 들어온 파티원은 지금 층부터 함께 오르고, 나간 사람은 기록을 가져가지 않습니다. 파티를 옮겨도 같은 층 보상은 학생마다 한 주에 한 번만 받습니다. 파티장이 나가면 다음 파티원이 파티장이 되고 기록은 그대로입니다. 마지막 한 명까지 나가 파티가 없어지면 그 주의 탑 기록도 지워집니다(받은 보상은 그대로, 새 파티에서는 이미 받은 층까지 보상 없이 다시 오름).
- **별의 탑 일지**: 도전 결과는 서버가 바로 정하지만, 전투는 대본(`R.towerScript`, 최대 18줄)으로 만들어 파티 창 맨 위에서 14~30초 동안 한 줄씩 흘려 보냅니다. 시작 시각은 서버가 정하므로 파티원 모두가 같은 장면을 같은 시각에 봅니다(SSE `tower` 이벤트로 시작·끝을 알림). 일지가 흐르는 동안에는 다른 파티원의 도전을 409로 막고, 층 표시·파티 채팅 알림·보상 우편 알림은 일지가 끝난 뒤에 나갑니다(보상 자체는 바로 저장). 최근 5번의 도전만 대본을 보관합니다.
- **미리보기 테스트 도구**: 아티팩트 미리보기의 설정 맨 아래. 학년 올리기, 과목 +5, 레벨 +10, 자원, 원정 단계 열기, 작업 즉시 끝내기, 정령·도전권 채우기. 서버판에는 없습니다.

## 5-6. 채팅 서버 · 운영자 · 슬로우 모드

- **보내기 검사 순서** (`POST /api/chat/send`): ① 같은 `nonce`(`학생id:nonce`, 2분 기억)면 새로 올리지 않고 처음 메시지 id를 돌려줌 → ② 마지막 전송 0.5초 안이면 429 → ③ 월드 슬로우 모드(운영자 제외) 429 `{ error, rate: true }`. 마지막 월드 전송 시각은 보내기에 성공했을 때만 기록합니다. 방송하는 메시지에도 `nonce`가 실립니다.
- **운영자**: `players.role = 'admin'`. DB에서 직접 바꾸거나(`UPDATE players SET role='admin' WHERE name_key='이름'`), 관리 페이지 「학생 관리 → 운영자로 지정」, 또는 환경 변수 `ADMIN_NAMES=이름1,이름2`(정식 학생만). 운영자인지는 서버만 판단합니다.
- **슬로우 모드**: 운영자가 월드 채팅의 「슬로우 모드 설정」 또는 `/slow 5`·`/slow off`. `POST /api/chat/slow {ch:'world', sec:0~600}` → 저장(재시작해도 유지) 후 모두에게 SSE `slow`. 관리자 토큰으로는 `POST /api/admin/slow`. 누가 언제 바꿨는지는 `oplog` 표와 관리 페이지 「운영 로그」에 남습니다.
- **SSE 처음 연결(init)**: `op`(운영자 여부), `slow: { world }`가 함께 옵니다.
- **방송 성능**: 메시지는 한 번만 JSON으로 만들고 0.2초마다 모아 모든 연결에 같은 문자열을 씁니다(동아리·파티 글은 그 사람에게만). 브라우저가 gzip을 받으면 SSE를 gzip으로 보냅니다(연결당 작은 압축 창, 약 24KB). 2,000명 테스트: 연결 실패 0, 메시지 24만 건 누락 없이 전달, 지연 중간 ~0.22초(묶음 간격만큼). gzip은 연결마다 따로 압축하므로 CPU를 조금 더 씁니다. 앞단 nginx에서 압축한다면 `SSE_GZIP=0`으로 서버 쪽 압축을 끄세요.
- **여러 프로세스(Redis)**: 지금 서버는 게임 상태(학생 메모리 캐시, SQLite)를 한 프로세스가 맡는 구조라 채팅만 Redis로 묶어서는 여러 대로 늘릴 수 없습니다. 한 프로세스로 2,000명이 여유 있게 돌아가므로(상태 p95 7.6ms) 지금은 넣지 않았습니다.

## 5-7. 동아리 레벨 · 부실 창고 · 계급, 거래소 시세, 아카데미 소식

- 동아리: 출석(+10)·아르크 기부(하루 200점)로 기여도 = 동아리 경험치. 레벨(최대 10)마다 정원 +2, 창고 +5칸, 부원 아르크·경험치 +0.5%. 부회장 최대 2명 + 회장이 만드는 계급 3개(권한: 초대·가입 승인 / 내보내기 / 공지·소개 / 창고 꺼내기). 회장은 부원이 있으면 나가거나 닫을 수 없음(먼저 위임). 닫을 때 창고의 아르크·장비는 회장에게 우편. 초대는 `guild_invites`(7일 뒤 정리), SSE `ginv`.

- 아카데미 소식: 새 학생 입학과 진급을 `world.news`에 모아(최근 50개) 광장 맨 위 한 줄과 「더보기」에 보여 줍니다.

## 5-8. 함께 원정 · 학과 · 기말시험 등급 · 처음 안내
- **함께 원정** (`server/exproom.js`, `GET /api/exprooms`, `POST /api/exproom` op=create·join·pos·leave·npc·npcdel·go): 방은 서버 메모리에만 있고 최대 4명. 방장이 출발시키거나(혼자도 됨) 4명이 차면 15초 뒤 출발. 30분 동안 아무도 출발시키지 않으면 닫힘. 방장은 NPC 아카데미 친구(방장 힘 60%)를 동행시킬 수 있음. 출발하면 사람마다 자기 빈 원정 슬롯에 `R.expPartyApply`로 원정이 들어가고(전리품은 각자), 결과는 혼자 원정과 같은 길로 받는다.
- **포지션** (`R.EXP_POS`, `R.expPartyPreview`): 선봉은 몬스터가 80% 확률로 노림(기사 +5%p, 수호 결계 +5%p, 최대 95%)·방어 +25%. 후열은 공격 주문 필요·공격 +10%·받는 피해 +10%. 지원은 보호막·치유 주문 필요·파티 피해 −15%·공격 −15%. 1명 늘 때마다 각자 몫 +5%.
- **학과** (`D.CLASSES`, `P.cls`): 기사 · 마법사. 가입 때 필수(`/api/register`의 `cls`). 기사가 수업으로 배운 일반 주문을 끼면 마검사. 학과 전용 수업(`cls` 붙은 과목: 검술·방패술 / 비전학)과 전용 주문은 그 학과에게만 보인다. 예전 학생은 마법사로 시작해 한 번 그냥 고를 수 있고(`setCls`), 그 뒤로는 전과시험.
- **기말시험 등급**: S·A·B·C 보상 표 `R.EXAM_REWARD`, 시험장의 예상 성적 `R.examPredict`.
- **모집 · 초대**: 방에서 「모집 알림」(한 줄 덧붙이기, 방마다 1분에 한 번)을 보내면 채팅 「모집」 탭(읽기 전용 채널 `recruit`)에 카드가 올라가고, 누구나 「살펴보기」(`GET /api/exprooms?id=`)로 방 사람들의 포지션·학과·레벨·전투력을 본 뒤 참가. 「친구 · 동아리원 초대」는 한 명씩 골라 보내고(op=invite, 10분 유지), 받은 사람은 원정 탭에 「초대 N」 표시.
- **학과 전용 주문 · 전과시험**: 기사 방패 강타 · 수호의 함성, 마법사 비전 폭발 · 마나 폭주(마검사는 방패 강타 · 비전 폭발). 학과를 바꾸려면 `clsExam`: 옮길 학과의 몸으로 시험관(추천 단계+2)과 대련해 이기면 옮김, 응시료 800×학년, 지면 하루 뒤.
- **게시판 답글**: 댓글에 답글(`parent`, 답글의 답글도 같은 줄기), 답글이 3개 이상이면 2개만 보이고 펼치기.
- **알림 기록** (`notes` 표, `GET/POST /api/notes`, 상태의 `noteN`, 채팅 스트림 `note` 이벤트): 내 글 댓글 · 내 댓글 답글, 거래소 판매, 파티 · 동아리 · 함께 원정 초대, 친구 신청 · 수락. 원래 화면·우편은 그대로 두고 기록만 모은다. 30일 지나면 지움.
- **처음 안내**: 가입하면 이야기 → 가이드 「처음」 → 화면 둘러보기. 한 기기에서 한 번(브라우저 설정 `tutDone`). 가이드 › 처음에서 다시 보기.

## 6. 운영

### 저장과 백업
- 학생 상태는 메모리에 두고 **5초마다** DB에 기록합니다. 종료 신호(`systemctl stop`, Ctrl+C)를 받으면 모두 저장하고 끝납니다.
- **12시간마다** `data/backups/`에 백업을 만들고 최근 14개를 남깁니다. `BACKUP_KEY`가 있으면 `.db.enc`(AES-256-GCM)로 저장합니다.
- 복구: 서버를 멈추고 백업 파일을 `data/arcanum.db`로 복사한 뒤 다시 켭니다. 암호화된 백업은 먼저 `BACKUP_KEY=키 node tools/decrypt-backup.js 백업.db.enc arcanum.db`로 풉니다.
- 서버를 옮길 때는 `data/` 폴더만 옮기면 됩니다.

## 7. 보안 · 개인정보

**저장하는 개인정보**: 학생 이름(닉네임), 비밀번호 해시, 기숙사, 사용한 초대코드, 프로필 글, 두상, 채팅. 이메일·실명·전화번호는 받지 않고, **IP 주소는 DB에 저장하지 않습니다**(속도 제한용으로 메모리에만 잠깐).

**암호화해서 저장하는 것**(AES-256-GCM, 키 `DATA_KEY`): 프로필(한 줄 소개·자기소개·공개 설정), 두상 이미지, 채팅 내용(RP·월드·파티), 신고 사유. DB 파일이나 백업이 새어 나가도 키 없이는 읽을 수 없습니다. 예전 버전에서 평문으로 저장된 것은 서버를 켤 때 한 번 암호화합니다. 학생 이름과 게임 진행 상태는 로그인·랭킹에 써야 해서 평문입니다(게임 안에서 원래 보이는 정보).

**방문자에게 보이지 않게**: 로그인하지 않은 사람에게는 학생 이름, 랭킹, 학생 수, 두상, 프로필, 채팅을 보내지 않습니다(`/api/world`, `/api/profile`, `/api/avatar`, 채팅 모두 로그인 필요). 로그인한 학생끼리도 레벨·전투력 공개 여부와 「자기소개는 친구에게만」을 고를 수 있고, 다른 학생의 입학일은 보이지 않습니다.

**비밀번호**: `HMAC-SHA256(서버 비밀 후추)` → `scrypt(N=2¹⁵, r=8)` + 학생마다 다른 소금. 되돌릴 수 없는 방식이라 서버 운영자도 원래 비밀번호를 알 수 없습니다. 후추는 DB에 없으므로 DB만 훔쳐서는 대입 공격을 시작할 수도 없고, 키까지 함께 털려도 scrypt 때문에 한 번 대입할 때마다 수십 ms와 32MB 메모리가 들어 대량 대입이 매우 비쌉니다. 8자 이상, 흔한 비밀번호·숫자만·이름 포함 비밀번호는 거절합니다. 예전 방식 해시는 다음 로그인 때 자동으로 새 방식으로 바뀝니다. *(어떤 해시도 「1234」 같은 아주 쉬운 비밀번호까지 지켜 주지는 못하므로 규칙으로 막아 둡니다.)*

- 로그인 세션: 30일. DB에는 토큰의 SHA-256 해시만, 브라우저는 HttpOnly 쿠키로만 보관(스크립트가 읽을 수 없음).
- 채팅 스트림: 주소에 로그인 토큰을 싣지 않고 30초짜리 1회용 입장권으로 연결.
- 관리자: 토큰 24자 이상, 해시 비교, `ADMIN_IPS`로 IP 제한. 비밀값은 root만 읽는 `/etc/arcanum.env`.
- 백업: `BACKUP_KEY`로 한 번 더 암호화. DB·백업·키 파일은 서버 계정만 읽기(0600).
- 속도 제한: 입학, 로그인(IP당 + 이름당), 행동, 프로필, 친구, 두상, 파티, 거래소 각각.
- 거래소: 서버에서만 계산하고, 같은 물건을 두 번 팔거나 사는 일이 없도록 상태를 한 번에 바꿉니다.(부계정으로 몰아주기 방지).
- 다른 사이트에서 보낸 쓰기 요청 거절(JSON만, Origin 검사), 보안 헤더(CSP, X-Frame-Options, HSTS, nosniff 등), systemd 샌드박스.
- **외부 API 키 없음**: AI·결제·메일 같은 외부 서비스를 부르지 않으므로 새어 나갈 키도, 사용량에 따라 붙는 토큰 비용도 없습니다.

- **테마**: 기기 설정 따라(밤하늘/한낮의 서고) · 밤하늘 · 한낮의 서고 · 노을 천문대 · 새벽 안개. 밝은 화면은 굵기가 있는 IBM Plex Sans KR로 그립니다.
- **캐시**: JSON 1KB 넘으면 gzip, `/api/world`는 ETag/304(시각 제외 해시), 두상은 `?v=`가 지금 버전일 때만 `immutable`, `index.html`은 `no-cache`.
- **종료(SIGTERM)**: 학생 상태 · 월드 보스 체력 · 소식/공지 · 채팅 글 번호를 DB에 쓴 뒤 닫습니다(경매 · 거래소 · 채팅 글은 원래 바로 기록).

## 9. 운영 전용 물약
- 연구 즉시 완료 물약(rsDone) · 학년 진급 물약(gradeUp)은 상점에 없고, 운영실 우편 보상으로만 지급합니다.
- 받은 플레이어에게만 서고의 진행 중 연구 옆 「즉시 완료」, 시험장의 「학년 진급」 버튼이 보입니다. 가이드에는 싣지 않습니다(내부용).

## 10. 아카데미 친구(NPC)
- 힘 비율은 R.NPC_FRAC (함께 원정 0.6 · 별의 탑 0.3) 한 곳에서 정합니다.
- 파티: 파티장이 `npcAdd {k}` / `npcRemove {k}`로 빈자리를 채웁니다(parties.npcs). 파티 보너스 · 탑 보상 우편 대상에서 빠집니다.
- 거래소: R.npcLot으로 늘 12개쯤(재료 3묶음 이상) 열어 두고, 팔리면 바로 · 15분마다 채웁니다. 매물은 1~2일 뒤 만료.
