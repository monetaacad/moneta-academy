# 업데이트 노트 정리 방법

게임 상단 「업데이트 노트」 버튼에 보이는 내용은 `shared/data.js`의 `D.PATCH`에 있다.

## 흐름
1. 하루 네 번(한국 시간 11 · 15 · 19 · 23시 5분) 예약 작업이 **기준 PR 이후 main에 머지된 PR** 수를 센다 (업데이트 노트 PR 자체는 세지 않는다).
2. 10개가 쌓이면 Claude가 항목 목록을 정리해 사용자에게 알린다.
   - PR 하나에 수정이 여러 개면 항목 단위로 나눈다.
   - 이웃한 PR끼리 비슷한 항목은 한 줄로 묶는다. 10개 경계에 걸친 비슷한 항목은 한 묶음으로 모은다.
   - 내부용(운영실 · 운영자 물약 · 운영 등급 · 취약점 · 서버 · 배포 · 시험 도구)은 ✕(제외 추천)로 표시한다.
3. 사용자가 제외할 번호를 알려 주면, 남은 항목을 공식 문장으로 다듬은 **노트 초안을 먼저 보여 주고 검사를 받는다.** 승인 전에는 파일을 고치지 않는다.
4. 승인을 받으면 그 문구 그대로 `D.PATCH` 맨 앞에 넣고 `var BUILD`를 올려 PR을 만든다. **머지하지 않고 둔다.**
5. 머지(배포)되면 서버가 공지 · 월드 채널에 한 번 알린다 (`patchPosted`).
6. 아래 기준 PR을 이번 노트의 마지막 PR로 고친다 (같은 노트 PR 안에서).
