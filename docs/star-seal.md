# 별의 인장 (환생) — 설계안

> 상태: **설계안만** (2026-10-21). 아래 「정해야 할 것」을 정한 뒤 구현한다. 숫자는 모두 첫 제안값.

## 1. 개념
- 마스터 과정 학생이 **「인장 의식」** 을 치르면 1학년으로 다시 입학한다.
- 졸업생의 배움이 **별의 인장** 으로 남아 영구 보너스로 바뀐다.
- 기존 설정을 그대로 잇는다: 학기 이야기 마지막 장에서 학장이 건네는 「별의 인장」, 도감 `seals`의 "다음 세대의 학생에게 유산으로 전해질 수 있다" (`shared/data.js`).

## 2. 의식 조건 · 인장 수
- 조건: 마스터 과정 + 심연 **101단계** 도달
- 인장 수: `3 + floor((최고 단계 − 기준) / 10)`, 기준 = `100 + 10 × (회차 − 1)` (회차가 쌓일수록 더 깊이 내려가야 같은 수를 얻는다)
  - 예: 첫 회 101단계 → 3개, 150단계 → 8개

## 3. 초기화 / 유지

| 초기화 | 유지 |
|---|---|
| 학년 · 레벨 · 능력치 배분 | 장비 · 소지품 (`R.canWear` 레벨 제한으로 높은 장비는 레벨이 오를 때까지 장착 불가) |
| 과목 레벨 · 시험 점수 · 시험 대기 | 사역마 · 알 · 휘장 |
| 원정 최고 단계(`maxStage`) · 보스 처치 기록 | 별조각 · 마석 · 마석가루 · 재료 |
| 학기 이야기(`story`) | 업적 · 칭호 · 도감 · 통계(`st`) |
| 연구(`rs`) — 인장 서약으로 일부 유지 | 기숙사 · 직업 · 동아리 · 친구 |
| 마나 · 지식 · 아르크 (아르크는 10% 유지) | 가방 확장 · 꾸미기 |

- 다시 오르면서 이야기 · 기말 S · 보스 첫 처치 보상을 **다시 받는다** (보상량은 줄여서).
- 「기말시험 S 7번」 같은 횟수 업적은 누적된다.

## 4. 인장 서약 (영구 보너스)
서약 하나에 인장 1~3개, 단계 상한 있음.

| 서약 | 효과(단계당) | 상한 |
|---|---|---|
| 선배의 지혜 | 경험치 · 과목 경험치 +5% | 10 |
| 마나의 샘 | 마나 획득 +5% | 10 |
| 빠른 학적 | 시작 학년 +1 (최대 4학년 시작) | 3 |
| 연구 유산 | 재입학 시 연구 단계 10% 유지 | 5 |
| 심연의 기억 | 원정 시작 단계 +10 (학년 상한 안에서) | 5 |
| 별의 가호 | 공격력 · 생명력 +3% | 무제한(비용 증가) |

- 「인장 다시 새기기」(아르크 또는 별조각)로 서약을 다시 고를 수 있다.

## 5. 보이는 것
- 학생 카드 · 랭킹 이름 옆에 인장 표시 (예: ✦3)
- 칭호: 「첫 인장」(1회) · 「세 번째 종소리」(3회) · 「별을 이어 쓰는 자」(10회)
- 랭킹: 「인장」 랭킹 추가
- 재입학 장면: 칼리오페호를 다시 타는 짧은 이야기 (학장 대사는 캐릭터 말투)

## 6. 구현 범위
- `shared/rules.js`
  - `P.seal = { n, spent, runs, oath: {} }` — 새 필드라 `fixState`에서 기본값만 채운다
  - `A.sealRite`(의식) · `A.sealOath`(서약) · `A.sealRecut`(다시 새기기)
  - 보너스는 `calc`의 경험치 · 마나 · 공격력 계산 지점에 반영
- `server/server.js`: 랭킹 `seal` 항목, 의식 직전 자동 백업 (되돌릴 수 없는 작업)
- `public/app.js`
  - 마스터 과정의 「모든 시험을 통과했습니다」 카드에 「인장 의식」 버튼
  - 확인 모달: 초기화 / 유지 목록 + 받을 인장 수, 「한 번 더 누르면 의식을 치릅니다」
  - 「인장 서약」 화면
- 가이드: 「마스터 과정」 항목에 인장 의식 설명 (공식 문장)

## 7. 정해야 할 것
1. 아르크: 전부 초기화 / 10% 유지 (거래소 경제 영향 큼)
2. 연구: 전부 초기화 / 서약으로 일부 유지 (투자가 커서 반발 가능)
3. 첫 의식 조건: 심연 101단계 / 더 낮게 (현재 졸업생 진도 확인 후)
4. 기존 레벨 · 원정 랭킹: 이번 회차 기준 / 누적 최고 기준
