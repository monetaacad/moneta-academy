# 성장 기록 CSV 열 설명

운영실 「성장 기록 내려받기」(`GET /api/admin/growth?days=N`)로 받는 CSV. 12시간마다(한국 시각 0시 · 12시 구간마다 처음 한 번, 10분마다 확인) 학생 한 명당 한 줄이 자동 저장된다(정지 · 게스트 · 삭제 제외). 2026-10-21까지는 하루 한 번이었고, 그 기록은 「0시」 칸으로 보인다.
학생 칸은 id를 해시한 익명 값이라 같은 학생의 날짜별 변화는 이어 볼 수 있지만 누구인지는 알 수 없다.

| 열 | 뜻 |
|---|---|
| date · student | 한국 날짜와 구간(「2026-10-22 12시」) · 익명 학생 |
| d · h | 입학 후 지난 날 수 · 시간 수 (h는 12시간 기록부터) |
| house · cls | 기숙사 · 학과 (mage / knight) |
| lvl · grade · stage | 레벨 · 학년 · 원정 최고 단계 |
| power | 순위표에 저장된 전투력 (마지막 저장 시점, 새 학생은 0일 수 있음) |
| ctM · ctK | 무한의 탑 마법사 · 기사 최고 층 |
| cup · act | 이번 주 대항전 점수 · 최근 24시간 접속(1/0) |
| kills … maxEnh | 누적 기록 (`P.st`): 처치 · 수업 시간/횟수 · 원정 · 보스 처치/도전 · 연구 · 물약 · 파견 · 교수 과제 · 결투 승리 · 월드 보스 공격 · 아르크/마나 누적 · 사역마 종류 · 영웅/전설 획득 · 최고 강화 |

**2026-10-21부터 추가 (그 전 날짜는 빈칸)**

| 열 | 뜻 |
|---|---|
| staffLv · staffR · staffEnh | 무기 칸 장비 레벨 · 등급(0 일반 ~ 4 전설) · 강화 |
| robe* · hat* · charm* · tome* | 로브 · 모자/투구 · 장신구 · 마도서/전술서 칸 (같은 형식) |
| gearLv | 낀 장비의 평균 장비 레벨 |
| powNow | 저장 시점에 다시 계산한 전투력 |
| powNoGear | 장비를 모두 뺐을 때 전투력 |
| gearPct | 전투력 중 장비 몫(%) = 1 − powNoGear / powNow |
| bdgGem · bdgLv · bdgQ | 달고 있는 휘장 보석 · 레벨 · 품질(1 = 100%) |
| subjSum | 과목 레벨 합 |
| al_int · al_wil · al_agi · al_vit · al_luk | 분배한 능력치 포인트 |
